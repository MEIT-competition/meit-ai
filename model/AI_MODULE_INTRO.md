# AI 모듈 소개 — 위험음 방향 인지 웨어러블

**작성**: 이주영 (인공지능 파트) · 팀 "팔방송이" · 2026 제5회 MEIT

---

## 1. 이 모듈이 하는 일

웨어러블 허리띠의 마이크로 수집된 소리를 실시간으로 분류해, 사용자에게 위험한 소리인지 아닌지·얼마나 위험한지를 판단하는 역할을 맡는다. 이 판단 결과(클래스 + 확신도)는 전자 파트의 방향 추정 결과와 결합되어, 최종적으로 어느 방향의 진동모터를 얼마나 강하게 울릴지 결정하는 데 쓰인다.

```
마이크 4채널 입력
   └→ [전자] 게이팅 주기마다 TDoA로 방향 추정, 해당 구간을 분류 대상으로 전달
        └→ [AI, 이 모듈] YAMNet 임베딩 추출 → 커스텀 분류층 → {클래스, 확신도}
             └→ [AI, 이예은] 위험도 판단 로직 → 진동 세기 결정 → 모터 구동
```

## 2. 왜 이렇게 설계했는가

### 2-1. 왜 YAMNet 전이학습인가
처음부터 오디오 분류 모델을 학습시키려면 수만 개 단위의 데이터가 필요하다. YAMNet은 이미 52만 개 이상의 오디오로 521개 소리를 구분하도록 사전학습되어 있어서, 그 지식을 그대로 가져와 위에 작은 분류층(Dense 512 → Dense 4)만 얹으면 소규모 데이터로도 충분한 성능을 낼 수 있다. 실제로 학습되는 파라미터는 52만 개뿐이라 CPU로도 학습이 빠르다 — 3주 안에 끝내야 하는 대회 일정에 적합한 선택이다.

### 2-2. 왜 4개 클래스인가
예선 기획안의 "돌발상황" 클래스는 정의가 모호하다는 심사 피드백(#4)을 받아, 본선에서 "충돌음(crash: 쾅 소리·급브레이크·유리 깨지는 소리)"으로 더 구체화했다. 최종 클래스는 horn(경적)·siren(사이렌)·crash(충돌음)·normal(일상소음) 4종이다.

### 2-3. 왜 위음성(False Negative) 최소화를 최우선으로 뒀는가
이 시스템의 사용 목적상, 위험음을 놓치는 것(위음성)이 일반 소음을 위험음으로 오인하는 것(위양성)보다 훨씬 치명적이다. 이 원칙을 다음 세 곳에 걸쳐 직접 반영했다.
- **학습 손실 함수**: 클래스별 가중치를 crash=3.0, siren/horn=2.0, normal=1.0으로 줘서, 위험음을 놓치는 오답에 더 큰 벌점을 준다
- **임계값 설계**: 분류 임계값을 낮게(0.4) 잡아 확신도가 다소 낮아도 위험 가능성을 전달하되, 확신도 0.7 이상/미만으로 진동 세기를 차등화(100%/60%)해 놓치지 않으면서도 사용자 피로를 줄인다
- **임계값 자동 탐색**: Recall 90% 이상을 만족하는 임계값 중에서만 오탐(false alarm)이 가장 적은 지점을 고르도록 탐색 순서 자체를 Recall 우선으로 짰다 (`threshold_search.py`)

### 2-4. 확신도 보정(Calibration)을 넣은 이유
확신도 구간별로 진동 세기를 다르게 매핑하는 설계(0.4~0.7 → 60%, 0.7 이상 → 100%)는, 모델이 뱉는 확신도 수치가 실제 정확도와 일치할 때만 의미가 있다. 신경망은 보통 과신(overconfident)하는 경향이 있어서, Temperature scaling으로 확신도를 보정하고 ECE(Expected Calibration Error)로 보정 전후를 비교한다 (`calibration.py`).

### 2-5. 노이즈 대응을 데이터 단계부터 반영한 이유
심사 피드백에서 가장 많이 지적된 부분(#2, #5, #6)이 실사용 환경의 잡음 처리와 오탐 관리였다. 허리띠 하드웨어가 나와야 실제 모터 노이즈를 녹음할 수 있지만, 그 전에도 공개 데이터만으로 danger 클립에 normal 소리를 여러 세기(SNR)로 섞어 합성 잡음 데이터를 만들어 학습에 포함시켰다 (`augment_data.py`). 이후 하드웨어가 나오면 실제 모터 on/off 쌍 녹음으로 교체·보강한다.

## 3. 데이터

| 클래스 | 공개 데이터셋 | 비고 |
|---|---|---|
| horn | UrbanSound8K, ESC-50 | |
| siren | UrbanSound8K, ESC-50, Kaggle Emergency Vehicle Siren Sounds | 라벨링 완료된 상태로 바로 사용 가능 |
| crash | ESC-50(glass_breaking), NINA Dataset | 공개 데이터가 가장 부족한 클래스, 자체 녹음 비중이 큼 |
| normal | UrbanSound8K 나머지 클래스 | 사람 말소리 등 보강 필요 |

모든 데이터는 16kHz mono, 4.5초 클립으로 통일하고, 원본 파일 단위로 train/val/test fold를 나눠 같은 녹음이 여러 split에 걸쳐 들어가는 데이터 누수를 방지했다.

## 4. 평가 지표

- **Recall(재현율)**: 핵심 지표. 목표 90% 이상 (위음성 최소화 원칙과 직결)
- **Precision, F1-score**: 보조 지표. 과도한 오탐 여부 점검
- **시간당 오탐 횟수**: 일상소음 상황에서 실제로 몇 번이나 잘못 울리는지 (심사 피드백 대응 지표)
- **ECE**: 확신도 보정 품질
- **모터 노이즈 유무에 따른 예측 변화율/확신도 하락폭**: sim-to-real gap 정량화 (`motor_noise_eval.py`)
